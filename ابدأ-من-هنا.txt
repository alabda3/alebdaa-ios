مشروع الإبداع للآيفون — نسخة شخصية للتثبيت خارج App Store
=======================================================

تاريخ التحضير: 2026-10-30

هذه الحزمة تحتوي مشروع Xcode الأصلي بعد تصحيحات ثابتة وملف GitHub Actions
لإنشاء IPA غير موقّع. ليست تطبيق IPA نهائياً، ولم يتم تنفيذ Xcode من هنا.

المتجر: https://alabda3.github.io/store/?source=pwa
اسم التطبيق: الإبداع
Bundle ID: io.github.alabda3
الحد الأدنى: iOS 15

أهم التصحيحات:
1- WKAppBoundDomains صار اسم الدومين فقط: alabda3.github.io
2- حذف ملفات Firebase التجريبية وCocoaPods وتوقف الإشعارات (غير مهيأة).
3- تنظيف Entitlements من صلاحيات APNs والدومينات المرتبطة وغيرها.
4- إزالة استدعاءات WebKit غير الآمنة وتسجيل مراقب التقدم المكرر.
5- إصلاح زر إغلاق شريط التنقل في بعض الصفحات الخارجية.
6- الحفاظ على اسم التطبيق والأيقونات ورابط المتجر ومكونات WebView الأصلية.

كيفية بناء IPA على Windows بدون Mac:
1- فك ZIP بالكامل مع المحافظة على المجلد المخفي .github ومجلد src.
2- ارفع محتويات المجلد إلى مستودع GitHub جديد (يفضل Public للبناء المجاني).
3- افتح Actions ثم Build Al-Ebdaa iPhone IPA (unsigned) ثم Run workflow.
4- عند نجاح البناء نزّل ملف alebdaa-iphone-unsigned من Artifacts.
5- فك ضغط artifact لتحصل على alebdaa-unsigned.ipa.
6- استخدم Sideloadly على Windows لتوقيع IPA بحساب Apple مجاني وتثبيته على آيفونك.

ملاحظات مهمة:
- لا ترفع Apple ID أو كلمة المرور أو شهادات توقيع إلى GitHub.
- ملف IPA الخارج من البناء غير موقّع: لا يتثبت بالنقر على رابط وحده.
- حساب Apple مجاني يحتاج تجديد توقيع التطبيق كل نحو 7 أيام.
- خدمات الإشعارات الأصلية غير مفعلة بهذه النسخة.
- GitHub Actions أو Xcode قد يظهر مشكلة بناء جديدة لم نتمكن من اختبارها هنا؛
  اعرض لنا سجل الخطأ عند ظهور أي مشكلة وسنصلحها خطوة بخطوة.
- لم نغيّر مستودع المتجر أو تطبيق الأندرويد إطلاقاً.
